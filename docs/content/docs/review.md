Manage code reviews: open, comment, approve, check status, and list.

## open

Create a new code review with a title, optional description, and base/head refs.

## comment

Add a comment to a review, optionally as a reply to an existing comment.

## approve

Record a review verdict: approve, request changes, or clear.

## status

View or update a review's status (draft, open, closed, merged).

## list

List code reviews, filtered by status, author, or text.
